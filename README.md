# 🌍 WorldWise
A modern travel tracking app built with **React**, **React Router**, and the **Context API**.

## 🚀 Features
* **Dynamic Map:** Click the map to record your travels.
* **Auth System:** Full authentication flow with protected routes.
* **State Management:** Complex state handled via `useReducer` and `Context API`.
* **Responsive UI:** Mobile-friendly minimalist design.

## 🛠️ Tech Stack
* React (Vite)
* Leaflet (Map)
* CSS Modules
* React Router
